# Watchdog Tool 产品文档

Watchdog Tool 是一个面向 Windows 桌面的进程守护工具。用户选择目标 EXE 后，工具会按配置的检查间隔持续观察进程状态，并在目标未启动、退出、无响应，或可选的文件夹文件堆积超时时自动恢复。

## v1.1 功能概览

- 通过文件选择器指定需要守护的 `.exe`。
- 配置检查间隔，控制监控频率。
- 配置无响应判定时间，用于处理带窗口 GUI 程序卡死。
- 可选启用文件夹堆积监控。
- 文件夹内持续存在文件超过指定秒数时，自动重启目标程序。
- 支持开始监控、停止监控、立即检查。
- 进程退出或未发现时自动启动。
- GUI 程序无响应时自动结束并重启。
- 无窗口后台进程按运行状态监控。
- 界面日志按时间、类型、内容展示，最多保留 500 条。
- 恢复类事件写入程序同级目录 `log`。

## 操作流程

1. 点击 `选择 EXE`，选择要守护的程序。
2. 设置 `检查间隔`。
3. 设置 `无响应判定`。
4. 如需按文件夹堆积重启，勾选 `启用文件夹堆积监控`。
5. 选择堆积文件夹，并设置 `堆积判定` 秒数。
6. 点击 `开始监控`。
7. 观察底部运行日志。
8. 如需修改配置，先点击 `停止监控`。

## 本地文件日志

以下恢复类事件会写入文件：

- 未发现进程并启动。
- 进程已退出并重启。
- 进程无响应并重启。
- 文件夹文件堆积超时并重启。
- 进程启动或重启完成。

日志路径：

```text
log\watchdog-yyyyMMdd.log
```

## 已知限制

- 当前版本不是 Windows Service，关闭桌面程序后监控会停止。
- 当前版本不保存历史配置，下次启动需要重新选择目标 EXE。
- 当前版本不提供远程告警或通知能力。
